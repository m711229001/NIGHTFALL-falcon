الرابط المُقدَّم (https://demoqa.com) هو موقع تدريبي (DemoQA) مخصص لاختبار الأتمتة وليس ثغرة حقيقية بحد ذاته. لا يوجد باراميتر أو حمولة محددة في المُدخل، لذلك لا يمكن تأكيد وجود ثغرة فعلية. قد يكون الهدف هو فحص إعدادات الأمان العامة للموقع (مثل غياب رؤوس الأمان HTTP، أو كشف معلومات الإصدارات، أو إمكانية الوصول لصفحات إدارية). بدون باراميتر وحمولة واضحة، التصنيف الأدق هو "معلوماتي/إعدادات خاطئة" وليس ثغرة قابلة للاستغلال المباشر.

**🎬 خطوات الاستغلال:**

1. التحقق من استجابة الموقع الأساسية عبر طلب GET إلى https://demoqa.com.
2. فحص رؤوس الاستجابة (Response Headers) للتأكد من وجود رؤوس أمان مثل HSTS وCSP وX-Frame-Options.
3. محاولة الوصول إلى مسارات شائعة مثل /robots.txt و/sitemap.xml و/.git/ لجمع معلومات.
4. فحص إصدارات الخوادم والتقنيات المستخدمة عبر رؤوس Server وX-Powered-By.
5. اختبار سلوك الموقع مع طلبات غير متوقعة (طرق HTTP مختلفة) لرصد أي رسائل خطأ تكشف معلومات.
6. توثيق النتائج وتحديد ما إذا كانت هناك إعدادات أمان مفقودة قابلة للاستغلال.
7. في حال عدم وجود ثغرة قابلة للاستغلال، يُصنَّف التقرير كـ "معلوماتي" وليس ثغرة فعلية.

**💻 كود PoC (جاهز للتنفيذ):**

```python
import requests

# رابط الهدف كما ورد في المُدخل
POC_URL = "https://demoqa.com"

# تعطيل تحذيرات SSL لتجنب ضجيج الشهادات في بيئات الاختبار
requests.packages.urllib3.disable_warnings()

# إرسال طلب GET للهدف مع مهلة زمنية
resp = requests.get(POC_URL, timeout=10, verify=False)

# طباعة رمز الحالة
print("Status Code:", resp.status_code)

# طباعة رؤوس الاستجابة لفحص إعدادات الأمان
print("\n--- Response Headers ---")
for k, v in resp.headers.items():
    print(f"{k}: {v}")

# فحص وجود رؤوس أمان مهمة
security_headers = [
    "Strict-Transport-Security",
    "Content-Security-Policy",
    "X-Frame-Options",
    "X-Content-Type-Options",
    "Referrer-Policy",
]
print("\n--- Missing Security Headers ---")
for h in security_headers:
    if h not in resp.headers:
        print(f"[MISSING] {h}")

# طباعة أول 500 حرف من محتوى الصفحة
print("\n--- Body Preview ---")
print(resp.text[:500])
```

**🛠️ الإصلاح:**

بما أن المُدخل لا يوضح ثغرة محددة، فإن الإصلاح العام يتمثل في تقوية إعدادات الأمان على الخادم: (1) إضافة رؤوس الأمان HTTP مثل HSTS وCSP وX-Frame-Options وX-Content-Type-Options. (2) إخفاء إصدارات الخوادم والتقنيات عبر تعطيل رؤوس Server وX-Powered-By. (3) تعطيل عرض الأدلة (Directory Listing) ومنع الوصول للملفات الحساسة مثل .git و.env. (4) تفعيل HTTPS إجبارياً مع إعادة التوجيه من HTTP. (5) مراجعة دورية للتكوينات باستخدام أدوات مثل OWASP ZAP أو Mozilla Observatory.

**🛠️ كود الإصلاح:**

```python
# مثال على إعداد رؤوس الأمان في Flask
from flask import Flask, Response

app = Flask(__name__)

@app.after_request
def set_security_headers(response: Response):
    response.headers["Strict-Transport-Security"] = "max-age=31536000; includeSubDomains"
    response.headers["Content-Security-Policy"] = "default-src 'self'"
    response.headers["X-Frame-Options"] = "DENY"
    response.headers["X-Content-Type-Options"] = "nosniff"
    response.headers["Referrer-Policy"] = "no-referrer"
    # إخفاء معلومات الخادم
    response.headers.pop("Server", None)
    response.headers.pop("X-Powered-By", None)
    return response

@app.route("/")
def index():
    return "OK"

if __name__ == "__main__":
    app.run()
```
