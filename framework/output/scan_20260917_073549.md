### 1. [MEDIUM] Clickjacking: missing X-Frame-Options / CSP frame-ancestors

**التصنيف:** Clickjacking

**🔗 رابط PoC (انسخه في المتصفح):**

```

```

**📝 الشرح:**

الرابط المقدم (https://httpbin.org) هو خدمة اختبار HTTP عامة وليس هدفاً مصاباً بثغرة محددة. لا توجد باراميترات أو حمولات أو أدلة استغلال في المدخلات، لذلك لا يمكن تأكيد وجود ثغرة فعلية. قد يكون هذا رابطاً مرجعياً أو هدفاً لاختبار الاتصال فقط. بدون تفاصيل إضافية (مثل باراميتر قابل للحقن أو دليل استجابة غير طبيعية) لا يمكن تصنيف الثغرة أو بناء PoC هجومي حقيقي.

**🎬 خطوات الاستغلال:**

1. تم استلام رابط عام (httpbin.org) بدون باراميتر أو حمولة محددة.
2. لا يوجد دليل على وجود نقطة إدخال قابلة للاستغلال.
3. لا يمكن تحديد نوع الثغرة (XSS, SSRF, SQLi, إلخ) من المعطيات.
4. الخطوة الوحيدة الممكنة هي التحقق من استجابة الخدمة الأساسية.
5. لا يمكن بناء سيناريو استغلال حقيقي بدون معلومات إضافية.
6. يجب إعادة جمع الأدلة: الباراميتر المصاب، الحمولة المستخدمة، والاستجابة الدالة على الثغرة.
7. بعد الحصول على هذه المعلومات يمكن بناء PoC دقيق وتصنيف CVSS مناسب.

### 2. [HIGH] CORS Misconfiguration

**التصنيف:** CORS

**🎯 CVSS:** 8.1
  
**Vector:** `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:N`
  
**⚠️ الأولوية:** 1

**🔗 رابط PoC (انسخه في المتصفح):**

```
https://httpbin.org?Origin=https://evil.httpbin.org
```

**الرابط الأصلي:** `https://httpbin.org`

**📌 الباراميتر:** `Origin`

**💉 الحمولة:** `https://evil.example.com`

**📝 الشرح:**

الثغرة هي CORS Misconfiguration (إعدادات CORS خاطئة) حيث يقوم الخادم بعكس قيمة ترويسة Origin في ترويسة Access-Control-Allow-Origin دون التحقق من قائمة بيضاء. هذا يسمح لأي نطاق خارجي (مثل evil.httpbin.org) بقراءة استجابات الخادم عبر JavaScript من المتصفح. الخطورة عالية لأنها قد تؤدي إلى تسريب بيانات المستخدم الحساسة (Tokens, PII) عند زيارة الضحية لصفحة خبيثة.

**🎬 خطوات الاستغلال:**

1. يقوم المهاجم بإنشاء صفحة HTML خبيثة على نطاق يتحكم به (evil.httpbin.org).
2. عند زيارة الضحية للصفحة، يقوم JavaScript بإرسال طلب fetch إلى https://httpbin.org مع credentials: 'include'.
3. المتصفح يضيف تلقائياً ترويسة Origin: https://evil.httpbin.org.
4. الخادم يعكس قيمة Origin في Access-Control-Allow-Origin ويرسل Access-Control-Allow-Credentials: true.
5. المتصفح يسمح للـ JavaScript بقراءة الاستجابة لأن النطاق مطابق.
6. يستخرج المهاجم البيانات الحساسة ويرسلها إلى سيرفره عبر fetch آخر.
7. يمكن أتمتة الهجوم عبر XSS أو حقن إعلانات لزيادة عدد الضحايا.

**💻 كود PoC (جاهز للتنفيذ):**

```python
import requests

# رابط PoC الكامل مع الباراميتر والحمولة
POC_URL = "https://httpbin.org?Origin=https://evil.httpbin.org"

# ترويسة Origin الخبيثة التي سيتم إرسالها
HEADERS = {
    "Origin": "https://evil.httpbin.org",
    "User-Agent": "Mozilla/5.0 (CORS-PoC)"
}

def main():
    # إرسال الطلب مع ترويسة Origin الخبيثة
    r = requests.get(POC_URL, headers=HEADERS, verify=False, timeout=15)
    print(f"[+] Status Code: {r.status_code}")
    print(f"[+] Response Headers:")
    for k, v in r.headers.items():
        print(f"    {k}: {v}")

    # فحص ترويسات CORS في الاستجابة
    acao = r.headers.get("Access-Control-Allow-Origin", "")
    acac = r.headers.get("Access-Control-Allow-Credentials", "")

    print("\n[+] CORS Analysis:")
    print(f"    Access-Control-Allow-Origin: {acao}")
    print(f"    Access-Control-Allow-Credentials: {acac}")

    if "evil.httpbin.org" in acao:
        print("\n[!] VULNERABLE: Origin is reflected in ACAO header!")
        if acac.lower() == "true":
            print("[!] CRITICAL: Credentials are allowed - full CORS bypass!")
    else:
        print("\n[-] Not vulnerable or Origin not reflected.")

    print("\n[+] Body (first 500 chars):")
    print(r.text[:500])

if __name__ == "__main__":
    main()
```

**🛠️ الإصلاح:**

يجب عدم عكس قيمة Origin مباشرة. بدلاً من ذلك، استخدم قائمة بيضاء (allowlist) صارمة للنطاقات المسموح بها، وتحقق من التطابق الكامل (exact match) وليس المطابقة الجزئية. أيضاً، لا تستخدم Access-Control-Allow-Credentials: true مع نطاقات غير موثوقة، وتجنب استخدام wildcard (*) عند الحاجة للـ credentials. يمكن استخدام regex صارم للتحقق من النطاق.

**🛠️ كود الإصلاح:**

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

# قائمة بيضاء صارمة للنطاقات الموثوقة
ALLOWED_ORIGINS = {
    "https://app.example.com",
    "https://admin.example.com",
}

@app.after_request
def add_cors_headers(response):
    origin = request.headers.get("Origin", "")
    # التحقق من التطابق الكامل مع القائمة البيضاء
    if origin in ALLOWED_ORIGINS:
        response.headers["Access-Control-Allow-Origin"] = origin
        response.headers["Access-Control-Allow-Credentials"] = "true"
        response.headers["Vary"] = "Origin"
    # لا نضيف أي ترويسة CORS إذا لم يكن النطاق مسموحاً
    return response

@app.route("/api/data")
def get_data():
    return jsonify({"secret": "sensitive-data"})

if __name__ == "__main__":
    app.run()
```

### 5. [HIGH] CORS Misconfiguration

**التصنيف:** CORS

**🎯 CVSS:** 8.1
  
**Vector:** `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:N`
  
**⚠️ الأولوية:** 1

**🔗 رابط PoC (انسخه في المتصفح):**

```
https://httpbin.org?Origin=https://evil.httpbin.org
```

**الرابط الأصلي:** `https://httpbin.org`

**📌 الباراميتر:** `Origin`

**💉 الحمولة:** `https://evil.httpbin.org`

**📝 الشرح:**

الثغرة هي CORS Misconfiguration (إعدادات CORS خاطئة) حيث يقوم الخادم بعكس قيمة ترويسة Origin في ترويسة Access-Control-Allow-Origin دون التحقق من قائمة بيضاء. هذا يسمح لأي نطاق خارجي (مثل evil.httpbin.org) بقراءة استجابات الخادم عبر JavaScript من المتصفح. الخطورة عالية لأنها قد تؤدي إلى تسريب بيانات المستخدم الحساسة (Tokens, PII) عند زيارة الضحية لصفحة خبيثة.

**🎬 خطوات الاستغلال:**

1. يقوم المهاجم بإنشاء صفحة HTML خبيثة على نطاق يتحكم به (evil.httpbin.org).
2. عند زيارة الضحية للصفحة، يقوم JavaScript بإرسال طلب fetch إلى https://httpbin.org مع credentials: 'include'.
3. المتصفح يضيف تلقائياً ترويسة Origin: https://evil.httpbin.org.
4. الخادم يعكس قيمة Origin في Access-Control-Allow-Origin ويرسل Access-Control-Allow-Credentials: true.
5. المتصفح يسمح للـ JavaScript بقراءة الاستجابة لأن النطاق مطابق.
6. يستخرج المهاجم البيانات الحساسة ويرسلها إلى سيرفره عبر fetch آخر.
7. يمكن أتمتة الهجوم عبر XSS أو حقن إعلانات لزيادة عدد الضحايا.

**💻 كود PoC (جاهز للتنفيذ):**

```python
import requests

# رابط PoC الكامل مع الباراميتر والحمولة
POC_URL = "https://httpbin.org?Origin=https://evil.httpbin.org"

# ترويسة Origin الخبيثة التي سيتم إرسالها
HEADERS = {
    "Origin": "https://evil.httpbin.org",
    "User-Agent": "Mozilla/5.0 (CORS-PoC)"
}

def main():
    # إرسال الطلب مع ترويسة Origin الخبيثة
    r = requests.get(POC_URL, headers=HEADERS, verify=False, timeout=15)
    print(f"[+] Status Code: {r.status_code}")
    print(f"[+] Response Headers:")
    for k, v in r.headers.items():
        print(f"    {k}: {v}")

    # فحص ترويسات CORS في الاستجابة
    acao = r.headers.get("Access-Control-Allow-Origin", "")
    acac = r.headers.get("Access-Control-Allow-Credentials", "")

    print("\n[+] CORS Analysis:")
    print(f"    Access-Control-Allow-Origin: {acao}")
    print(f"    Access-Control-Allow-Credentials: {acac}")

    if "evil.httpbin.org" in acao:
        print("\n[!] VULNERABLE: Origin is reflected in ACAO header!")
        if acac.lower() == "true":
            print("[!] CRITICAL: Credentials are allowed - full CORS bypass!")
    else:
        print("\n[-] Not vulnerable or Origin not reflected.")

    print("\n[+] Body (first 500 chars):")
    print(r.text[:500])

if __name__ == "__main__":
    main()
```

يجب عدم عكس قيمة Origin مباشرة. بدلاً من ذلك، استخدم قائمة بيضاء (allowlist) صارمة للنطاقات المسموح بها، وتحقق من التطابق الكامل (exact match) وليس المطابقة الجزئية. أيضاً، لا تستخدم Access-Control-Allow-Credentials: true مع نطاقات غير موثوقة، وتجنب استخدام wildcard (*) عند الحاجة للـ credentials. يمكن استخدام regex صارم للتحقق من النطاق.

```python
    except requests.exceptions.RequestException as e:
        print(f"[-] Request failed: {e}")

if __name__ == "__main__":
    main()
```

```python
from urllib.parse import urlparse, urlunparse

ALLOWED_HOSTS = {"api.trusted.com", "cdn.trusted.com"}

def safe_fetch(user_url: str) -> str:
    parsed = urlparse(user_url)
    if parsed.scheme not in ("http", "https"):
        raise ValueError("Scheme not allowed")
    if parsed.hostname not in ALLOWED_HOSTS:
        raise ValueError("Host not allowed")
    # متابعة الطلب بشكل آمن
    return urlunparse(parsed)
```
